# 首页 Logo 的复用来源

素材从用户提供的桌面 `三为矿安Logo_Codex复用包_20260929.zip` 提取。仅保存完整原点阵头文件和两张原始预览，未执行包内脚本，也未修改其所述的其他工程。

`ui_sanwei_logo.h` 是生成器的输入资料，不加入固件编译。原图为 78×48，逐行低位优先，每行 10 字节，共 480 字节；SHA256 为 `d601ac119c997a54d82dd01c6750d3c34074bee96319c49a250cd2bed171b84d`。

`sunwing_hd_reference.png` 是用户随后提供的 920×498 高清原图，保留原文件字节。当前默认从这张原图生成上方标志及英文，不再二次缩小复用包中的低分辨率英文。

当前首页 Logo 位于 `(9,5)`，品牌画布为 72×36。上方标志为 28×15，放在本地 `(22,0)`；英文为 71×8，放在 `(0,16)`；中文仍用复用包资源适配成原有的 60×11，放在 `(0,25)`，其像素及实际位置与上一版一致。仅扩大英文可用宽度，避免把包内的原首页位置或整页背景套用到当前工程。

英文按照原图的连通笔画分离成七个字母，i 的点与主体分别取形，不能按空白列拆分，因为斜体 w/i 的横向边界存在重叠。逐字宽度为 `[8,10,10,13,4,10,10]`，相邻字母空一列；保留共同基线、i 点下的一行空白及 g 的底笔。图形二值化阈值为 140，英文为 160，中文为 128。原图裁切排除注册符号和最下方的边界线，当前裁切参数仅适用于这份 920×498 素材。

在项目根目录运行 `python -B tools/generate_home_assets.py`，输出到当前 `CH584_V1_0_1/APP/include/ui_home_assets.h`。标题和其他字模沿用现有生成流程；`--brand-reference` 指定同规格的高清原图。显式传入 `--logo-source tools/ui_assets/sanwei_logo/ui_sanwei_logo.h` 可重现上一版 60×36 适配；`--legacy-brand` 保留最初的字体生成方式，`--reference` 仍选择原布局参考图生成方式。`--lishu-font` 和 `--english-font` 只作用于这些最初的生成方式。

本轮验证和实际绘图预览见 `tools/ui_preview/logo_hd_output/`，上一版结果保留在 `logo_output/`。烧录及实屏显示尚未验证。
